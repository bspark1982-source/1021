ISW·싱크탱크의 영문 지도, 도표, 인포그래픽, PDF 페이지에서 영어만 찾아 한글로 바꾸고 나머지는 원본 그대로 둡니다. 자동 번역 뒤 사람이 검수·수정하는 단계를 넣어 보고서에 바로 쓸 수 있는 품질을 만듭니다.

가운데 막대를 좌우로 끌어 비교 · 원본: ISW·AEI Critical Threats Project, 2026.10.20 (시연용 인용, 저작권은 원저작자에 있음)

왜 만들었나

ISW 일일 보고서와 싱크탱크 자료의 지도·도표를 매일 한글 보고서에 넣어야 하는 실무 문제에서 출발했습니다.

기존 방식

  • 지도 속 영어를 하나하나 옮겨 적고 번역
  • 그림 편집 프로그램으로 글자를 지우고 한글을 다시 얹음
  • 지명·부대명 표기가 작업자·날짜마다 달라짐
  • 번역 앱은 사진 위에 번역문을 덮어 보여 줄 뿐, 보고서용 이미지로 저장·수정이 어려움

ImageKoTranslator

  • 글자 위치·크기·색을 자동으로 찾아 같은 자리에 한글로 교체
  • 그래프·표의 숫자, 축척, 로고는 자동 보호(지우지 않음)
  • 용어집으로 지명·부대명 표기를 고정해 매일 같은 표기 유지
  • 사람이 번역문·글자 크기·위치를 고친 뒤 PNG·JPG·PDF로 저장

작동 방식

자동으로 80%를 처리하고, 남은 20%는 사람이 빠르게 다듬는 구조입니다.

1

열기

이미지·PDF를 열거나 화면 캡처를 바로 붙여넣기. PDF는 페이지를 골라 작업.

Ctrl+O · Ctrl+Shift+V
2

글자 인식

PP-OCRv6 기반 무료 OCR이 영어 줄을 찾고, 문장·문단·범례 항목 단위로 묶음. 기울어진 해협·바다 이름도 각도까지 인식.

F5
3

번역

용어집을 먼저 적용하고 무료 번역기로 문단 단위 번역. 막히면 파파고·DeepL 웹 결과를 붙여넣기.

F6
4

검수·저장

번역문, 글자 크기·색, 위치를 고치고 원본/결과를 비교한 뒤 이미지나 PDF로 저장.

Space · Ctrl+S

주요 기능

실제 ISW 지도로 시험하며 다듬은 기능들입니다.

🎯

원본 스타일 유지

배경색·글자색·크기·굵기를 원본에서 추정해 적용. 범례 글자 크기는 항목끼리 통일.

🔢

숫자·로고 보호

그래프·표 수치, 축척, 방위표, ISW·CT 로고 글자는 지우지도 번역하지도 않음.

🧭

지도 전용 처리

기울어진 글자는 같은 각도로 교체, 도시 점(●)은 남기고 지명만 교체, 범례는 기호 옆 왼쪽 정렬.

📖

용어집

하르키우·후티 반군 등 표기를 고정. 고친 번역은 버튼 하나로 용어집에 쌓여 다음부터 자동 적용.

✍️

수작업 편집

상자 끌어 이동·크기 조절, 병합·분할, 놓친 영역 추가, 배경색 스포이드, 되돌리기.

📄

PDF 지원

본문 글자층은 원래 크기·색 그대로, 페이지 속 지도 글자는 OCR로. 여러 쪽 일괄 처리, 원본 뒤 대조 페이지 삽입.

편집 화면

왼쪽에서 상자를 직접 다루고, 오른쪽에서 원문·번역을 검수합니다.

번역 완료 번역 전 숫자·로고 등 보호 선택됨

설치와 실행

처음 한 번만 설치하면 이후에는 더블클릭으로 실행합니다.

  1. 내려받아 압축 풀기 — zip 안에서 바로 실행하지 말고 먼저 풀기
  2. install 더블클릭 — 필요한 패키지를 .venv 폴더에 설치 (3~10분). 지원 버전 파이썬을 자동으로 찾아 사용
  3. run 더블클릭 — 프로그램 실행
  4. 열기 → F5(인식) → 검수 → Ctrl+S(저장)

필요 환경

  • Windows 10 / 11 (64비트)
  • Python 3.10 ~ 3.14 (3.15만 있으면 install이 3.13 설치를 시도)
  • 설치 시 인터넷 필요, 글자 인식은 오프라인
  • 자동 번역 사용 시 인터넷 필요

알려진 한계

  • 곡선을 따라 휘어진 글자, 글자 간격을 넓게 띄운 세로 글자는 자동 인식이 안 됨 → "상자 추가"로 직접 입력
  • 지형 음영 위 지명은 배경색 사각형으로 덮임 (내용 전달 우선 설계)
  • 무료 번역기는 품질·안정성이 일정하지 않음 → 검수 단계 필수

보안 주의

  • 자동 번역을 켜면 문장이 외부 번역 서버로 전송됨
  • 공개 자료(ISW·싱크탱크)에만 사용하고, 비공개 자료는 "자동 번역 안 함"으로 두고 내부 절차에 따라 번역
  • 글자 인식(OCR)은 PC 안에서만 처리
