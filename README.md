# ImageKoTranslator — 영문 지도·도표 한글화 편집기

ISW·싱크탱크의 영문 지도, 도표, 인포그래픽, PDF 페이지에서 영어만 찾아 한글로 바꾸고 나머지는 원본 그대로 두는 Windows 설치형 편집기입니다.

- 소개·다운로드 페이지: 이 저장소 `public/` 폴더가 Vercel로 배포됨
- 프로그램 소스: [`source/`](source/) — 설치·사용법은 [`source/README.md`](source/README.md)
- 내려받기: [`ImageKoTranslator_v1.1.1.zip`](public/ImageKoTranslator_v1.1.1.zip)

정책제도 3기 AI 실무 과정 바이브코딩 프로젝트.

예시 이미지 원본: Institute for the Study of War & AEI's Critical Threats Project (2026.10.20). 기능 시연 목적의 인용이며 저작권은 원저작자에 있습니다.
