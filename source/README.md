# 이미지·PDF 한글화 편집기 (ImageKoTranslator) v1.1.1

ISW·싱크탱크의 영어 지도·도표·인포그래픽 이미지, PDF 페이지의 영어를 한글로 바꿔 저장하는 Windows용 설치형 프로그램입니다.
유료 API 키 없이 무료 OCR(오프라인)과 무료 번역기를 쓰고, 번역 결과는 사람이 검수·수정하는 구조입니다.

## 1. 설치 (처음 한 번)

1. 압축을 원하는 폴더에 풉니다 (예: `D:\ImageKoTranslator`). 경로에 한글이 있어도 되지만, 문제가 생기면 영문 경로로 옮기세요.
2. `install.bat`를 더블클릭합니다. 필요한 패키지(수백 MB)를 `.venv` 폴더에 설치합니다. 처음에는 몇 분 걸립니다.
3. 끝나면 `run.bat`를 더블클릭해 실행합니다.

- 지원 파이썬: **3.10 ~ 3.14** (글자 인식 패키지 onnxruntime 기준). 3.15만 설치되어 있으면 install.bat이 3.13 설치를 자동으로 시도하며, 실패하면 python.org에서 3.13을 받아 설치한 뒤 다시 실행하세요. 여러 버전이 같이 있어도 됩니다.
- 글자 인식(OCR) 모델은 패키지에 포함되어 있어 설치 후에는 **인터넷 없이** 인식됩니다. 자동 번역만 인터넷이 필요합니다.
- 오류 내용을 보려면 `run_debug.bat`로 실행하세요. 오류 기록은 `error_log.txt`에 남습니다.

## 2. 작업 순서

| 단계 | 버튼(단축키) | 내용 |
|---|---|---|
| 열기 | 열기(Ctrl+O) / 끌어놓기 / 붙여넣기(Ctrl+Shift+V) | PNG·JPG 등 이미지, PDF, 작업 파일(.ikt.json). 화면 캡처(Win+Shift+S) 후 바로 붙여넣기 가능 |
| ① 글자 인식 | F5 | 영어 줄을 찾아 문장·문단 단위로 묶음. 숫자만 있는 글자(그래프·표 수치, 축척 등)는 **보호** 처리되어 지우지도 번역하지도 않음 |
| ② 자동 번역 | F6 | 용어집 먼저 적용 → 무료 번역기로 문단 단위 번역 (인식 후 자동 실행 옵션 기본 켜짐) |
| 수정 | 오른쪽 목록·편집칸 | 아래 "수정 기능" 참고 |
| ③ 저장 | Ctrl+S / PDF 내보내기 / 작업 저장 | PNG·JPG 저장, 번역 PDF 생성, 나중에 이어서 고칠 작업 파일 저장 |

### 수정 기능
- 번역문 수정: 목록의 한글 칸 더블클릭, 또는 아래 "한글 번역" 칸에 입력
- 원문 수정: OCR이 잘못 읽은 영어를 고친 뒤 "선택 블록 다시 번역"
- 글자 크기·굵게·정렬·글자색·배경색 변경. "배경색 스포이드"를 누르고 이미지를 클릭하면 그 색으로 덮음
- 상자를 끌면 한글 위치 이동, 상자 오른쪽 아래 모서리를 끌면 크기 조절
- 여러 블록 선택(Ctrl+클릭 또는 빈 곳 드래그) 후 글자·색을 바꾸면 한꺼번에 적용
- 병합(Ctrl+M): 따로 인식된 줄을 한 문장으로 합침 / 줄 단위 분할(Ctrl+D) / 삭제(Del)
- 상자 추가(A): 인식이 빠진 영역을 드래그하면 그 영역만 인식·번역
- 번역 대상 ↔ 보호 전환: 숫자로 오인된 글자를 번역하거나, 번역하지 말아야 할 글자(고유명 약어 등)를 보호
- 스페이스: 원본 ↔ 결과 비교, B: 상자 숨기기, Ctrl+Z / Ctrl+Y: 되돌리기 / 다시 실행, Ctrl+휠: 확대·축소

### 지도 글자 처리
- **기울어진 글자**(해협·바다·강 이름 등)는 같은 각도로 지우고 한글도 같은 각도로 씁니다. 편집칸의 "회전" 값으로 각도를 바꿀 수 있고, 0으로 하면 가로쓰기가 됩니다.
- **범례**는 항목별로 묶고(두 줄짜리 항목은 한 항목으로), 범례 기호 옆에 붙도록 왼쪽 정렬합니다.
- **도시 점(●) 옆 지명**은 점을 남기고 글자만 바꿉니다.
- 자동으로 못 잡는 글자: 곡선을 따라 휘어진 글자(예: Gulf of Oman), 글자 사이를 넓게 띄운 세로 글자(예: R E D S E A). "상자 추가(A)"로 영역을 그린 뒤 번역 칸에 직접 입력하고, 필요하면 회전 값을 조정하세요.

### PDF
- 페이지를 골라 ① 인식. 인식 방식 기본값은 "글자층+이미지 OCR"로, PDF 본문 글자는 원래 글자 정보(크기·색)를 그대로 쓰고, 페이지 속 그림(지도·도표)의 글자는 OCR로 읽습니다.
- 번역 메뉴 → "여러 페이지 일괄 인식+번역"으로 여러 쪽을 한 번에 처리한 뒤 페이지별로 검수
- PDF 내보내기 방식: 원본 페이지를 번역본으로 교체 / 원본 뒤에 번역 페이지 삽입(대조용) / 번역 페이지만
- 번역된 페이지는 이미지로 들어갑니다(글자 검색 불가). 원본 PDF 파일은 바뀌지 않습니다.
- PDF 해상도: 파일 메뉴 → PDF 해상도(기본 200 DPI). 작은 글자가 많으면 250~300

## 3. 번역기

| 선택 | 특징 |
|---|---|
| 구글 번역 (무료 웹) | 기본값. 품질 양호. 비공식 무료 경로라 많이 쓰면 일시 차단될 수 있음 |
| MyMemory | 구글이 막힐 때 대안. 하루 사용량 제한, 품질은 낮은 편 |
| 자동 번역 안 함 | 용어집만 적용하고 나머지는 직접 입력 |

**번역기가 막히거나 품질이 아쉬울 때**: 번역 메뉴 → "원문 내보내기" → 전체 복사 → 파파고·DeepL 웹사이트에 붙여넣기 → 결과 복사 → "번역문 붙여넣기". `[번호]`가 유지되면 블록에 자동으로 들어갑니다.

> 주의: 무료 웹 번역기는 입력한 문장이 외부 서버로 전송됩니다. 비공개·보안 자료는 "자동 번역 안 함"으로 두고 내부 절차에 따라 번역하세요.

## 4. 용어집 (`glossary.csv`)

- 원문 전체가 용어와 같으면(지명·범례 등) 그대로 한글로 바꾸고, 문장 속 용어는 번역 전에 한글로 치환해 표기를 고정합니다.
- 프로그램 안 "용어집" 버튼으로 편집하거나 엑셀로 직접 편집(UTF-8 CSV, `en,ko` 2열)
- 블록 번역을 고친 뒤 "용어집에 추가"를 누르면 다음부터 같은 표기로 자동 번역
- 한글 칸에 `=`를 넣으면 **번역하지 않고 원본 그대로 보호**합니다. ISW·Critical Threats 로고 글자가 기본으로 등록되어 있습니다. 보호 블록을 선택하고 "용어집에 추가"를 누르면 `=`로 저장됩니다.
- 대소문자까지 같은 항목을 먼저 찾습니다. 그래서 로고의 `INSTITUTE FOR THE STUDY OF WAR`는 보호하고, 문장 속 `Institute for the Study of War`는 "전쟁연구소(ISW)"로 번역하는 식으로 구분할 수 있습니다.
- 기본으로 넣어 둔 지명·기관명 표기는 예시입니다. 소속 기관의 표기 기준에 맞게 고쳐 쓰세요.

## 5. 글꼴

기본은 맑은 고딕입니다. `fonts` 폴더에 TTF/OTF 파일(예: Pretendard-Regular.otf, Pretendard-Bold.otf)을 넣고 다시 실행하면 상단 "글꼴" 목록에 추가됩니다.

## 6. 문제 해결

- **install.bat에서 pip 오류**: 사내망 프록시가 있으면 `pip`가 막힐 수 있습니다. 인터넷이 되는 PC에서 설치한 폴더(.venv 포함)를 통째로 복사해도 같은 파이썬 버전이면 동작합니다.
- **onnxruntime DLL 오류**: [Microsoft Visual C++ 재배포 패키지(x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)를 설치하세요.
- **번역이 전부 실패**: 인터넷 연결 확인 → 번역기를 MyMemory로 변경 → 원문 내보내기/붙여넣기 방식 사용
- **지도에서 작은 지명이 인식 안 됨**: 상자 추가(A)로 직접 영역을 그리거나, PDF는 해상도를 높여 다시 열기
